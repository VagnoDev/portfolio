## 🚀 Features

- **High Performance**: Built on top of [Astro](https://astro.build) for a lightning-fast experience.
- **Premium Design**: Modern aesthetics with glassmorphism and smooth micro-animations.
- **Responsive**: Fully optimized for mobile, tablet, and desktop.
- **Project Showcase**: Detailed view of my featured projects.
- **Commissions List**: A dedicated section for live websites I've built.
- **Non-Draggable UX**: UI elements are protected from accidental dragging for a solid app feel.

## 🛠️ Tech Stack

- **Framework**: Astro 
- **Icons**: Font Awesome & Devicons
- **Styling**: Vanilla CSS (Custom Glassmorphism)
- **Deployment**: Vercel

## 📦 Local Development

Get started locally by following these steps:

1. **Clone the repository**:
   ```sh
   git clone https://github.com/VagnoDev/portfolio.git
   ```

2. **Install dependencies**:
   ```sh
   npm install
   ```

3. **Run in development mode**:
   ```sh
   npm run dev
   ```

4. **Build for production**:
   ```sh
   npm run build
   ```
